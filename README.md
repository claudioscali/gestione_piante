# 🌱 Gestionale Giardino

Mini gestionale sviluppato in Python per la gestione di un giardino domestico.

## Funzionalità

- Registrazione di nuove piante
- Gestione di diverse tipologie di piante
- Irrigazione singola o totale
- Raccolta di frutti e foglie
- Controllo delle necessità di irrigazione
- Simulazione del passaggio del tempo
- Logging delle operazioni principali
- Gestione degli errori tramite eccezioni

## Tecnologie utilizzate

- Python 3
- Programmazione orientata agli oggetti (OOP)
- Ereditarietà
- Gestione eccezioni
- Logging

## Esempi di funzionalità

- Aggiungere una nuova pianta
- Annaffiare una pianta
- Annaffiare tutte le piante
- Raccogliere frutti o foglie
- Visualizzare lo stato del giardino
